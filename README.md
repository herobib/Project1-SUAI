# Modular Track Platform (MTP)
It is educational project for SUAI. This is a tracked platform onto which various modules can be mounted. It features a web interface for remote control.
# Functional
- Remote control web-interface
- Bucket module
- Camera module, but not work
# Technologies and tools
- Code: C++ Arduino framework, React TypeScript
- 3D-models: SolidWorks2024(some 2025)
- Microcontroller: ESP32S3-Devkit-C1 N8R8
# Project structure
- `/code/SrcCode/Project` - ESP code
- `/code/web/frontend` - web interface code
- `/models` - 3D models
- `/assets` - Other documentation
